# Gmail Account Sort
**An LSPosed module that sorts Gmail accounts alphabetically (A–Z) by email address in the account switcher.**

## Installation

1. Install the APK from Releases.
2. Enable the module in LSPosed Manager.
3. Select Gmail as the target application.
4. Force stop Gmail and reopen it.

## Compatibility

- Gmail "2026.11.02.1015914183.Release" and later.
- Supports classic and Bento account switcher layouts.

Compatibility with future Gmail updates is not guaranteed.
